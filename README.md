# Lab8_WE_Git1

Web Engineering Lab 8 - Responsive E-Commerce Product Gallery.

## What it does
- Product cards in a CSS Grid using `repeat(auto-fit, minmax(250px, 1fr))`
- Fully responsive with no explicit media queries
- Hover animations on cards, images and buttons

## Files
- `index.html` - page structure
- `style.css` - grid layout and animations
- `README.md` - this file

## Run
Open `index.html` in any browser.
